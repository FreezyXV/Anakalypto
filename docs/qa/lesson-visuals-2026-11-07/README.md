# Preuves de recette — extension des schémas

Les captures sont des rendus natifs du navigateur, sans retouche. Le dossier est distinct de la revue initiale des vingt découvertes.

- 'gallery-measures.json' : limites des légendes pour les 72 vues sur ordinateur.
- 'mobile-states.json' : trois états par sujet, contrôle au clavier, légende et explication, dimensions à 320 px.
- 'additional-article-routes.json' : les vingt autres chemins de leçons associés.
- 'placeholder-link.json' : clic depuis le corps de leçon vers le schéma, titre sous l’en-tête.
- 'coexistence-soap.json' : ancien atelier et complément chimique, identifiants et dimensions.
- 'console-final.json' : chargement neuf sans alerte ; historique de développement conservé séparément.
- 'alveoli-final-article.jpg' : atelier dans sa véritable page Expanded, vue « Échanger les gaz ».

Les captures mobiles montrent la troisième vue sélectionnée et son focus clavier ; le défilement naturel peut placer le titre de l’atelier au-dessus de la fenêtre. Les captures ordinateur présentent les trois vues côte à côte dans une galerie de recette retirée avant compilation.
