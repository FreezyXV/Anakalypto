# Preuves de recette — arts, mesures et informatique

Captures natives du navigateur, sans retouche. Les planches à 1280 px présentent les trois états dans une galerie temporaire, retirée avant compilation. Les captures à 320 px montrent le troisième état dans la vraie page de leçon, avec focus clavier. Le défilement peut placer le titre au-dessus de la fenêtre.

- `desktop-bounds.json` : limites des textes pour les 36 dessins de la planche.
- `mobile-states.json` : contrôle de 36 états sur les douze vrais articles, légendes, explications, dimensions et police rendue.
- `placeholder-link.json` : retour depuis la leçon au titre du schéma sous l’en-tête.
- `catalogue-card.json` : bonne association de la vignette, figure décorative et absence de lien imbriqué.
- `production-states.json` : 36 états sur les douze articles servis par `next start` à 1280 px, avec la base locale.
- `production-console.json` : absence d’erreur et d’alerte pendant cette recette compilée.
- `console-final.json` : absence d’erreur et d’alerte sur un chargement neuf.
- `perspective-final-article.jpg` : atelier dans la vraie leçon, troisième vue.
