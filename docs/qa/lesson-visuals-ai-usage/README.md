# Usages des modèles d’IA — 9 novembre 2026

Huit dessins spécifiques : multimodalité, hallucinations, exécution locale et quantification, aides à la lecture et transcription, médias synthétiques, récupération de documents, robotique vision-langage-action et vision-langage. Les huit articles ont été lus avant association exacte.

Les huit planches de trois états sur ordinateur et les huit captures du dernier état sur téléphone ont été relues à l’œil. Le robot a ensuite été dégagé de la table et sa légende de pied raccourcie ; une capture de la leçon complète confirme le placement final. 24 états manipulés au clavier à 320 px, texte SVG minimal 12,55 px, aucun débordement, une seule figure visible et légende/détail conformes. 24 états contrôlés sous `next start` local, sans erreur de console ; preuves JSON jointes. Les boîtes ne sont pas des boutons dans les dessins : les contrôles restent des boutons HTML accessibles.

Les deux segments du bras conservent leurs longueurs et atteignent exactement les poses choisies. La quantification de quatre échantillons 8 bits vers quatre niveaux est calculée ; tests sur toutes les 256 valeurs et la borne d’erreur. Les sorties « Une tasse », « Bonjour » et le musée sont préparées, les avatars entièrement fictifs. Aucune caméra, IA, reconnaissance de visage ou commande de robot n’est exécutée.

82 tests isolés réussis, TypeScript réussi, ESLint du périmètre réussi. Compilation locale réussie. Sources d’origine dans les schémas : annonces historiques OpenAI, articles LLaVA/RT-2/RAG, documentation llama.cpp et Google Accessibilité, rapport NIST sur les contenus synthétiques ; limites de provenance recoupées avec C2PA.

Aucun import ou déploiement. Aucun changement des textes d’articles, dates de vérification, anciens ateliers ou données de production. Pas de test avec apprenants ou lecteur d’écran réel.
