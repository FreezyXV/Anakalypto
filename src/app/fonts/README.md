# Archivo

Variable font from the official [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/archivo), downloaded on 2026-10-10. `Archivo-OFL.txt` preserves the bundled license. The source font is used without modification.

The application uses `next/font/local` to retain Archivo while avoiding the query-based Google Fonts URLs rejected by the installed Next.js Google font loader. Spectral keeps its existing configuration.
